# Resume fonts

The PDF generator embeds static instances of the same Google Fonts families used by `styles.css`:

- Montserrat Medium and SemiBold
- Roboto Condensed Medium

Font files were sourced from the Google Fonts repository (`ofl/montserrat` and `ofl/robotocondensed`) and instantiated from the variable fonts for ReportLab. Both families are distributed under the SIL Open Font License; the respective license texts are included alongside the fonts.
